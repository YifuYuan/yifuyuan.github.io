# Academic Portfolio Website
A clean, responsive academic portfolio showcasing research projects and professional experience.

## Quick Start
**Running locally**
1. Clone repository or download and unzip
2. Open terminal, cd into root directory (where `index.html` is located)
3. Run `./start_dev_server.sh` or `python3 -m http.server 8000`
4. Open http://localhost:8000/

## What's next?
- Open `index.html` and customize your personal information
- Replace images in the `images/` folder with your own
- Read `DEVELOPMENT.md` for detailed development guide
- Deploy to GitHub Pages or your preferred hosting platform

## Features
- **Responsive design** for mobile and desktop
- **Dark/light theme** toggle
- **Project showcases** with dedicated pages
- **Academic timeline** for experience and education
- **Research publications** and teaching sections
